Outlook Tips at Tricks na Nakakatipid ng Oras Mo Araw-Araw

Sanay sa Gmail pero Outlook ang gamit ng client? Eto ang mga shortcut na nakakatipid ng oras.

Aling Outlook ang gamit mo?

  • Classic OutlookDesktop, pinaka-kumpleto
  • New OutlookDesktop, mas modern
  • Outlook on the webKung bawal mag-install
  • Outlook mobilePara sa quick checks

Hindi makita ang setting? Check sa Microsoft Support.

Top time-savers

  • Quick StepsIlang actions sa isang click
  • RulesAuto-sort ng newsletters at notifications
  • CategoriesKulay para sa email at calendar
  • TemplatesMy Templates o Quick Parts
  • Schedule SendDarating sa umaga ng recipient
  • Follow up flagsMay reminder date

Color categories

  • Pula: Urgent, kailangan ng boss
  • Dilaw: Waiting for reply
  • Berde: For my action
  • Asul: FYI lang

Naka-on ang Focused Inbox? I-check ang "Other" tab ilang beses sa isang araw.

Delegate access, hindi password

Password sharing

  • Walang record kung sino gumawa
  • Delikado sa security
  • Mukhang ikaw ang boss
vs

Delegate access

  • May record ng bawat action
  • Setup ng IT admin o boss
  • Malinaw na "on behalf of"

Shortcuts sa Windows desktop

  • Ctrl + RReply
  • Ctrl + Shift + RReply All
  • Ctrl + FForward, hindi search!
  • Ctrl + Shift + MBagong email
  • Ctrl + Shift + ABagong appointment
  • Ctrl + 1 or 2Mail o Calendar

Daily Outlook routine

  1. 1I-scan ang red categories
  2. 2Sagutin ang 2-minute replies
  3. 3I-flag ang para sa boss
  4. 4I-check ang conflicts sa susunod na 48 oras
  5. 5Linisin gamit ang Quick Steps
  6. 6I-schedule send ang drafts bago mag-out
